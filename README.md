# AI-Based Security Monitoring & Threat Detection Platform (SecureWatch)

## Overview
SecureWatch is a full‑stack security monitoring web application built with Django (Python) backend and React/TypeScript frontend. It includes a rich set of SIEM detection rules, ML models for anomaly detection, and interactive dashboards.

## Dependencies
- **Python** 3.12+ (virtual environment recommended)
- **Node.js** 18+ (for the frontend)
- **Docker** (optional, for containerised deployment)
- **SQLite** (default DB, no external service required)

## Installation
1. **Clone the repository** (if not already local):
   ```bash
   git clone https://github.com/Saikiran-12345/AI-BASED-SECURITY-MONITORING-THREAT-DETECTION-PLATFORM.git
   cd "AI-Based Security Monitoring & Threat Detection Platform"
   ```
2. **Backend setup**:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate   # PowerShell
   pip install -r backend/requirements.txt
   ```
3. **Frontend setup**:
   ```bash
   cd frontend
   npm install               # installs dependencies
   cd ..
   ```

## Build
### Frontend (production bundle)
```bash
cd frontend
npm run build    # creates `dist/` folder
cd ..
```
### Docker image (optional)
```bash
docker build -t securewatch .
```

## Run
### Development servers (quick start)
```bash
# Backend API
cd backend
..\venv\Scripts\python.exe manage.py runserver 8000

# Frontend dev server (Vite)
cd ../frontend
npm run dev      # serves at http://localhost:5173
```
### Docker compose (all services)
```bash
docker-compose up -d   # starts backend and frontend containers
```

## Usage
- Open the frontend in a browser: `http://localhost:5173` (or the Docker‑exposed port).
- Default admin credentials (generated by the data‑generation script):
  - **Username:** `admin`
  - **Password:** `adminpass`
- Explore the dashboards, alerts, incidents, and risk analysis panels.

## Additional commands
- **Generate synthetic data** (populates the DB and trains ML models):
  ```bash
  cd backend
  ..\venv\Scripts\python.exe manage.py generate_security_data
  ```
- **Run tests**:
  ```bash
  cd backend
  ..\venv\Scripts\pytest
  ```
